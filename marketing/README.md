# marketing/

Arte promocional (ex.: exports do `designcraft`) vive aqui.

## Escopo

- Fora de `assets/` e de `media-src/frames|audio`.
- Não é processado por `build:images`, `build` nem `validate`.
- Não é referenciado pelo manifesto nem contado em `budget.json`.

## Pipeline (fora do build)

Nenhum passo de build roda sobre este diretório. Os arquivos são entregues
já otimizados (dimensões finais de entrega).
