## Deviations from Assessment

- The assessment suggested using `photocraft-cli`/`designcraft-cli`/`effectcraft-cli`/
  `figcraft-cli`/`soundcraft-cli`, but these are GUI-first applications with no
  batch authoring CLI surface; only `vectorcraft-cli` supports headless
  `run`/`export`. The remediation was performed with `vectorcraft-cli` plus
  hand-refined SVG (within the sanitizer allow-list), which is the only viable
  path that preserves the vector pipeline and provenance chain.
- Raster (PNG/JPG) masters were not used; SVG was retained for vector fidelity
  and sanitizer compliance, as the briefs prefer.
